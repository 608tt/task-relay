# Contributing

Open an issue with a small reproducible example, expected behavior, OS/browser or CLI version, and actual behavior. Remove prompts, tokens, personal vocabulary and project paths from logs before posting.

Run `npm test` and `npm run build` on Node.js 22+. There are no npm dependencies. Changes to adapters or scheduling need regression tests; document the difference between simulated and live verification. Keep permissions narrow and avoid analytics, hosted credentials or silent background execution.

This project is independently developed and is not an official platform integration.
